# 📋 Instrucciones de entrega de la actividad

## 1. Crear el fork

Crea un **fork de mi repositorio**, manteniendo su contenido original tal cual.

## 2. Desvincular el fork

Entra en tu nuevo fork y abre **Settings** (Configuración).

Busca la opción **Leave fork network** y sigue los pasos para desvincularlo del repositorio original.

## 3. Hacer privado el repositorio

Una vez desvinculado, cambia la visibilidad del repositorio a **Private** desde los ajustes.

## 4. Añadirme como colaborador

En **Settings → Collaborators**, invítame como colaborador para que pueda acceder al repositorio y revisar la actividad.

## 5. Publicar la actividad como release

Cuando termines la actividad, crea una **release** en tu repositorio:

- Añade una etiqueta de versión, por ejemplo, `v1.0`.
- Escribe un título que identifique la actividad.
- Incluye una breve descripción del trabajo realizado.
- Adjunta los archivos de la entrega.

## ✅ Lista de comprobación

- [ ] Fork creado con el contenido original.
- [ ] Repositorio desvinculado de la red de forks.
- [ ] Visibilidad configurada como privada.
- [ ] Invitación de colaborador enviada.
- [ ] Actividad publicada como release.
